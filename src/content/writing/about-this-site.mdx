This site renders Markdown and MDX files from a [public repository](https://github.com/unforcedagi/techne-www). Astro builds those files into web pages, and GitHub Pages hosts the result. The writing files live in `src/content/writing/`.

## Adding a piece

Create a `.md` file in that directory, or use `.mdx` when a piece needs a component. Add frontmatter with a title, authors, date, summary, and draft status. The [README](https://github.com/unforcedagi/techne-www#readme) provides the format and local preview commands.

Preview the piece locally, then submit the change through a pull request. Changes merged into the main branch run the site's checks and deploy through GitHub Actions. Drafts appear in the development preview but are excluded from the production site. Their source files are still public in the repository.

## Publishing beyond this site

Atproto publishing is still being decided. The content schema includes optional metadata for future integration, but the site does not publish records to atproto. Standard.site and the Techne SDK remain options; neither is connected here.
